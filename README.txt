PARTVISION DIRECT DEPLOYMENT

This package has exactly one website file: index.html.
No React, Vite, npm, GitHub Action or external assets are required.

1. Delete every old repository file.
2. Upload index.html and .nojekyll to the ROOT of the main branch.
3. GitHub Settings > Pages > Source: Deploy from a branch.
4. Select main and /(root), then Save.
5. Wait 2 minutes and hard refresh.
